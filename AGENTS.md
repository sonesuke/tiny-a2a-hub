# AGENTS.md

This file serves as a policy declaration for this repository.

## Language Policy

**This repository uses English as its primary language.**

All documentation, code comments, commit messages, issues, and discussions should be in English.

---

## Purpose

This document declares the language policy to ensure consistency across:
- Documentation (README, docs/, inline comments)
- Code (variable names, function names, comments)
- Communication (issues, PRs, discussions)
- Commit messages

---

## Exception

Internal team communications or discussions may occur in other languages, but any artifacts stored in this repository should be in English.
